Créditos

Los modelos 3D configurados en esta aplicación proceden de la Human Reference Atlas / HuBMAP CCF 3D Reference Object Library y se usan bajo licencia CC BY 4.0.

Referencia: Browne K., Cross L.E., Herr II B.W., Record E.G., Quardokus E.M., Bueckle A., Börner K. HuBMAP CCF 3D Reference Object Library.

Las ilustraciones de respaldo, interfaz y contenido didáctico de este prototipo fueron creados específicamente para Anatomía AR 2.0.

Usar realidad aumentada

1. Abre la aplicación desde un teléfono compatible mediante HTTPS.

2. Selecciona una estructura con modelo 3D.

3. Pulsa Ver en AR, permite el acceso cuando el dispositivo lo solicite y apunta hacia una superficie.

4. Mueve el teléfono lentamente hasta detectar el plano y coloca el modelo.
